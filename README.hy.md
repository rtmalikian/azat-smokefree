# Ազատ — Թող ծխելը, մնա ազատ 🇦🇲

**🌐 Լեզու / Language / Язык:** Հայերեն · [English](README.md) · [Русский](README.ru.md)

**👉 Փորձիր հիմա՝** https://rtmalikian.github.io/azat-smokefree/

**Ազատը** ծխելը թողնելու **անվճար հավելված ա՝ հիմնված գիտության վրա**։ Առանց քարոզի, առանց ամոթի, առանց վախեցնելու՝ մենակ գործիքներ, որոնք հարգում են քո ընտրությունը։ **Հայերեն, ռուսերեն ու անգլերեն։**

Հայաստանում **գրեթե երկու տղամարդուց մեկը ծխում ա**։ Ազատը օգնում ա թողնել՝ կամ աստիճանաբար կրճատել, անձնական պլանով, գայթակղության SOS գործիքներով, ամենօրյա հիշեցումներով ու մրցանակներով։

## ✨ Ինչ կա ներսում

- **🗺️ Պլանի հրաշագործ** — ամբողջությամբ թող կամ աստիճանաբար կրճատի (հետազոտությունները ցույց են տալիս՝ երկուսն էլ աշխատում են), «եթե՝ ուրեմն» պլաններով
- **🛟 Գայթակղության SOS** — 4 Գ-ն (Հետաձգիր, Խորը շնչիր, Ջուր խմիր, Ուրիշ բան արա), 4-7-8 շնչառություն, 3 րոպեանոց «ալիք», զանգ աջակցող մարդուն
- **🪞 «Ինչի՞ եմ ծխում»** — հանգիստ ինքնաճանաչում, ներառյալ սերունդների հարցը (*ընտանիքիդ տղամարդիկ ծխու՞մ էին*), կապված հաղթահարման գործիքների հետ
- **🏔️ Արարատ** — ծուխը բառացիորեն ցրվում ա Արարատի վրայից, երբ առանց ծխելու օրերդ շատանում են
- **🎯 Առիթների քարտեզ** — 8 հայկական իրականության առիթ (առավոտյան սուրճ ☕, խմիչք 🥂, ընկերներ, հացից հետո, սթրես, գործի ընդմիջում, ձանձրույթ, ղեկ)՝ հաղթահարման խորհուրդներով
- **🏋️ Վարժություններ** — քո պատճառները, փողի հաշվիչ, արժեքներ, աջակցող մարդ
- **🏆 Մրցանակներ** — 18 նվաճում՝ ժամանակ, խնայած փող, հաղթած գայթակղություններ, շարքեր, ներառյալ 🏔️ Արարատ մրցանակը 100 օրվա համար
- **📚 Փաստեր** — կարճ ու անկեղծ, ամեն պնդում՝ աղբյուրով
- **🔔 Հիշեցումներ** — ամենօրյա ծանուցումներ առանց սերվերի
- **🔒 Գաղտնիություն** — առանց մուտքի, առանց հաշիվների, առանց հետևելու։ Ամեն ինչ մնում ա քո հեռախոսում։

## 🧠 Ինչու Ազատը ուրիշ ա

Վախեցնող ու ամաչեցնող հաղորդագրությունները կարան **հակառակ ազդեն**․

- **Առանց հրամայելու։** «Պիտի թողնես, թե չէ…» լեզուն զայրույթ ու դիմադրություն ա առաջացնում, որ դեպի սիգարետ ա մղում ([53 հետազոտությունների ամփոփում](https://academic.oup.com/hcr/article/52/1/38/8178818))։
- **Օգուտի մասին, ոչ թե վախի։** Օգուտի մասին հաղորդագրությունները մարդկանց ավելի են պահում, քան վախը։ Ամեն էկրան այն մասին ա, թե ինչ ես **շահում**՝ ազատություն, փող, շունչ, հպարտություն։
- **Մեր պապերը լեռներ են հաղթահարել։ Դու մի գայթակղությունը կարաս հաղթահարել։**
